## Featured Projects

**ENSO Streaming Pipeline** — Arquitectura Big Data en tiempo real para monitoreo de riesgo de inundaciones por El Niño. Ingesta multi-fuente (NOAA, INAMHI, INOCAR, NASA POWER) vía Kafka, procesamiento con Spark, Data Lake en HDFS/Parquet y dashboard interactivo sobre FastAPI.

**Kichwa Translator** — Sistema multilingüe de speech-to-text y traducción a Kichwa ecuatoriano. Combina OpenAI Whisper (ASR) con un modelo NLLB-200 de Meta afinado, desplegado con FastAPI y Docker.

**Supply Chain Simulation** — Simulación de optimización de inventario en cadena de suministro construida con SimPy, con análisis de escenarios y métricas de desempeño.

**Personal Portfolio** — Portafolio personal en React + Vite con estética glassmorphism / liquid-glass.
